# Merkassets

- `logo-primary.svg` — woordmerk op licht, Energy Orange `.nl`, segmentbalk 3:2:1
- `logo-reversed.svg` — negatief op inkt/verloop
- `avatar.svg` — “kg” op merkverloop, voor favicon en social
